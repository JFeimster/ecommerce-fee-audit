# Platform Fee Audit Widget

Embed the HTML, CSS, and JS together in a Wix/WordPress-safe container. Recommended maximum display size is 1200px × 940px. Configure `data-theme`, `data-default-product`, `data-cta-url`, `data-launch-url`, `data-support-url`, `data-source-context`, `data-campaign`, `data-partner-id`, `data-referrer`, and `data-compact`. It never accepts sensitive files.
