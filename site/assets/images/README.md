# Site Images

Use this folder for public-safe images that need to load from the live Vercel site.

Recommended assets:

- hero graphics
- product card visuals
- social preview images
- landing-page screenshots
- partner-safe illustrations
- embed preview graphics

Path rule:

```text
site/assets/images/
```

Public URL pattern after deployment:

```text
/assets/images/file-name.ext
```

Do not store private client exports, raw Shopify/Amazon/Stripe data, bank files, credentials, API keys, screenshots containing sensitive financial data, or real customer records here.
