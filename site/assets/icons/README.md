# Site Icons

Use this folder for public-safe icon and UI assets used by the static site.

Recommended assets:

- `favicon.svg`
- `apple-touch-icon.png`
- `audit-mark.svg`
- `platform-badge-shopify.svg`
- `platform-badge-amazon.svg`
- `platform-badge-stripe.svg`

Do not place private client exports, platform data, credentials, API keys, or real financial records in this folder.
