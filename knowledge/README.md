# Knowledge Library

This directory contains the AI Platform Fee Audit Copilot operating library.

## Canonical Sources

The taxonomy, master transaction schema, reconciliation rules, output schema, privacy policy, and action-confirmation policy are the primary operating authorities.

## Subdirectories

- `business-models/`: monetization, packaging, recurring revenue, and licensing
- `products/`: DIY, DWY, and DFY offer definitions
- `sales/`: positioning, objections, pricing questions, and upgrade paths
- `implementation/`: Wix, Notion, onboarding, and recurring-service execution
