# Source Image Assets

`assets/images/` is source and internal working storage only. It is not a production-public asset directory and files here are not served by the static site.

`site/assets/images/` is the production-public image directory. New public assets must be reviewed for privacy, rights, relevance, and production suitability, then copied into `site/assets/images/` before the site references them.

Never place secrets, client data, unredacted screenshots, bank or payout exports, private financial files, credentials, or other sensitive material in either `assets/images/` or `site/assets/images/`.
